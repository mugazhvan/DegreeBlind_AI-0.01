# Degree Blind

> **Hire Skills. Not Degrees.**

Degree Blind is an AI-powered GitHub repository analysis platform that helps recruiters evaluate developers based on publicly available technical work instead of relying solely on academic qualifications.

By analyzing repository structure, code quality, documentation, engineering practices, and project organization, Degree Blind generates evidence-based insights that support fairer, skill-focused hiring.

## Why Degree Blind?

Many talented developers are overlooked because automated hiring systems often prioritize academic qualifications before technical ability.

Degree Blind shifts the focus from **where someone studied** to **what they can build**.

## Core Principles

- Evidence over assumptions
- Skills over credentials
- Transparency over black-box scoring
- AI assists recruiters—it does not replace them
